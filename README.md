# Credit Card Fraud Detection

This project demonstrates a robust approach to detecting fraudulent credit card transactions using Python and machine learning.  

As a Data Analyst with 6 years of experience, I focus on **data preprocessing, feature engineering, and handling highly imbalanced datasets**, providing actionable insights and reproducible pipelines.

## Key Highlights
- **Data Cleaning & Exploration:** Checked for missing values and analyzed class imbalance.
- **Feature Scaling:** Used `RobustScaler` to handle outliers in transaction amount and time.
- **Train/Test Split:** Ensured stratified split to maintain fraud ratio.
- **Imbalanced Data Handling:** Applied SMOTE to balance training data for model learning.
- **Evaluation:** Kept test set imbalanced to reflect real-world fraud detection performance.

## Dataset
[Credit Card Fraud Detection Dataset](https://www.kaggle.com/mlg-ulb/creditcardfraud)
